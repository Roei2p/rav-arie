# סיפורי צדיקים – הרב אריה מאיר

מערכת לזיכוי הרבים: תמלול הדיסקים, ומהם דפים לשבת, פרקי פודקאסט ואירועים.

## מבנה
- `queue.txt` – תור הדיסקים לתמלול (מזהה תיקייה בדרייב | שם הדיסק). דחיפה של הקובץ מפעילה תמלול.
- `scripts/transcribe.py` – תמלול עברית עם `ivrit-ai/whisper-large-v3-turbo-ct2`.
- `transcripts/<דיסק>/TrackXX.txt|json` – התמלולים. כל רצועה נשמרת ונדחפת מיד כשהיא מסתיימת.
- `content/<דיסק>/` – התוכן שנבנה מהתמלולים: דף לשבת, דף פרק לפודקאסט, לוח שנה, אירועים.

## מעקב מהטלפון
לשונית **Actions** בריפו מראה את ההרצה. התמלולים מופיעים בתיקייה `transcripts` בזמן אמת.
